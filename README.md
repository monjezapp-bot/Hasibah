# حاسبة شيفت 🛵

## خطوات رفع التطبيق على GitHub Pages

### الخطوات (10 دقائق فقط)

1. افتح github.com وسجّل حساب جديد
2. بعد التسجيل اضغط زر "New repository" (علامة +)
3. اسم الـ repository: اكتب بالظبط: `tarek-shift`
4. اختار "Public" وفعّل "Add a README file"
5. اضغط "Create repository"
6. في الصفحة الجديدة اضغط "uploading an existing file"
7. ارفع الملفات الأربعة: index.html، manifest.json، sw.js، icon-192.png، icon-512.png
8. اضغط "Commit changes"
9. روح Settings > Pages > Source: اختار "main" > Save
10. بعد دقيقة رابطك هيكون: https://USERNAME.github.io/tarek-shift

### تثبيت التطبيق على الهاتف
**Android:** افتح الرابط في Chrome > النقاط الثلاث > "إضافة إلى الشاشة الرئيسية"
**iPhone:** افتح الرابط في Safari > زر المشاركة > "إضافة إلى الشاشة الرئيسية"
